مراحل آسان برای استفاده از دیباگر که ممکن است ندانید. مثال زیر را با `Next.js` و Chrome DevTools ببینید:

# مراحل

این اسکریپت را اجرا کنید، می‌توانیم development را با دیباگر متصل اجرا کنیم.

```bash
NODE_OPTIONS='--inspect' next dev
```

این خروجی‌ها را خواهید دید:

```bash

For help, see: https://nodejs.org/en/docs/inspector
```
